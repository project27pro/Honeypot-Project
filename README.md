# 🛡️ Honeypot Intrusion Detection System
مشروع نظام السيرفر المفخخ لرصد الهجمات السيبرانية بلغة Python.

## 🚀 المميزات
- رصد حقيقي للمنافذ الضعيفة (SSH, HTTP).
- لوحة تحكم ويب لعرض الهجمات المكتشفة.
- تسجيل كامل لعنوان IP المهاجم ووقت الهجوم.

## 🛠️ التشغيل
1. تثبيت المكتبات: `pip install flask`
2. تشغيل السيرفر: `python honeypot.py`
3. تشغيل الموقع: `python app.py`
